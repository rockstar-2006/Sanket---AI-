# Sanket AI – Record Module

This branch contains the Record module developed as part of the Sanket AI project.

## Features

- Hand gesture recording using MediaPipe
- Support for one-hand and two-hand gestures
- Save custom signs to Firebase Firestore
- Personal sign library
- Sign recognition
- Animated sign playback
- Delete saved signs

## Technologies Used

- Next.js
- TypeScript
- MediaPipe Tasks Vision
- Firebase Authentication
- Firebase Firestore
- Tailwind CSS

## Module Purpose

The Record module allows users to record hand gestures, save them as custom signs, recognize recorded signs, and manage their personal sign library.

## Integration

This module is intended to be integrated into the main Sanket AI project. Firebase Authentication and Firestore configuration may need to be adapted to the main project's existing setup.
